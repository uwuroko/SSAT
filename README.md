## SSAT⋆ ˚｡⋆୨୧˚
SSAT (Support System for Astronauts) is a software developed for supporting space travels. Its main goal is to calculate the distance in hours/days to destiny "A" to destiny "B" and the only thing that is required from the crew member is typing in the system their name, the distance and the ship's speed. Besides, the program was writte in a warm tone, to soothe the space loneliness.
